# Günlük Seri

Sade bir alışkanlık takipçisi. Ana ekranda yalnızca bugünün alışkanlıkları yazıyla görünür; yaptığını yukarı kaydırınca kaybolur. Seriler, takvim ve son 14 günün grafiği "Rapor" menüsünde.

**Telefona kurmak için:** [GunlukSeri.apk'yı indir](../../releases/latest/download/GunlukSeri.apk)

Veriler yalnızca telefonda saklanır. Rapor > Yedek bölümünden yedek alabilirsin.
